    캘린더
    직접 일정, CRM의 다음 연락일과 지원 업무 마감일을 한눈에 보고 Google Calendar와 연결합니다.
    Google Calendar 연결
    Google 계정 연결 후 직접 등록한 일정은 저장·수정·삭제할 때 Google Calendar에도 함께 반영됩니다.
    Google 연동은 Google Cloud에서 Calendar API를 사용 설정하고, 현재 HTTPS 주소 또는 localhost를 승인된 JavaScript 원본으로 등록해야 합니다. 클라이언트 ID는 비밀번호가 아니지만 사내 관리자만 변경하는 것을 권장합니다.
    연결 안 됨
    직접 등록 일정 CRM 다음 연락일 지원 업무 마감일 Google Calendar

    새 일정
    CRM에 직접 일정을 등록합니다. Google Calendar가 연결되어 있으면 저장·수정·삭제 내용도 함께 반영됩니다.
    Google OAuth 웹 클라이언트 ID 확인 방법
    Google Cloud에서 아래 순서대로 한 번만 설정한 뒤 발급된 클라이언트 ID를 캘린더 화면에 붙여 넣습니다.
    1
    프로젝트를 선택하고 Calendar API를 사용 설정합니다.Google Cloud Console에서 기존 프로젝트를 선택하거나 새 프로젝트를 만든 뒤, API 및 서비스의 라이브러리에서 Google Calendar API를 찾아 사용 설정합니다.
    2
    Google Auth Platform을 설정합니다.Branding에서 앱 이름과 지원 이메일을 입력하고 Audience를 설정합니다. 외부 사용자를 선택해 테스트 중이라면 실제 연결할 Google 계정을 테스트 사용자에 추가합니다.
    3
    웹 애플리케이션 클라이언트를 만듭니다.Google Auth Platform의 Clients에서 Create Client를 누르고 Application type을 Web application으로 선택합니다.
    4
    승인된 JavaScript 원본을 등록합니다.아래 CRM 원본 주소를 Authorized JavaScript origins에 추가합니다. 경로나 파일명 없이 https://도메인과 필요한 포트까지만 등록합니다.
    5
    클라이언트 ID를 복사합니다.생성된 값 중 .apps.googleusercontent.com으로 끝나는 Client ID를 복사해 이 CRM의 입력란에 붙여 넣고 ‘클라이언트 ID 저장’과 ‘Google 계정 연결’을 차례로 누릅니다.
    HTTPS 배포 주소를 확인해 주세요.
    HTML 파일을 PC에서 직접 열면 Google 로그인을 사용할 수 없습니다. HTTPS 웹주소 또는 localhost에서 CRM을 실행한 뒤 해당 원본 주소를 등록해야 합니다.

    중요도 산정 기준
    자동 중요도는 예상매출, 성사확률, 영업단계, 그룹 분류를 함께 반영합니다. 항목 상세에서 수동 중요도를 지정하면 자동 산정보다 우선 적용됩니다.
    자동 점수 = 예상매출(백만원) × 성사확률 × 단계 가중치 × 그룹 분류 가중치
    금액이 비어 있으면 실제 매출 판단이 어려우므로 낮게 계산됩니다. 연구·검토성 그룹은 기본적으로 보수적으로 계산됩니다.
    그룹 분류 가중치
    매출과 가까운 그룹일수록 같은 금액·확률이라도 중요도가 높게 잡히도록 조정합니다.
    회사명 이미지 검색
    API 키 없이 일반 이미지 검색을 열어 명함의 로고와 회사명을 확인한 뒤, 확인한 사명을 저장합니다.
    사용 방법: 일반 이미지 검색은 검색어로 로고를 확인합니다. Google Lens를 사용할 때는 먼저 명함 이미지를 저장한 뒤 Lens 화면에 업로드하세요. 검색 결과는 이 CRM에서 자동으로 읽지 않으므로, 확인한 회사명을 아래에 입력해 저장합니다.
    명함 스캔

    처음 사용하는 CRM 시작 안내
    복잡한 설정부터 바꾸지 않아도 됩니다. 아래 순서대로 한 건만 등록해 보면 전체 흐름을 이해할 수 있습니다.
    1
    연락처를 등록합니다.명함 스캔·업로드 또는 직접 추가로 고객 담당자를 저장합니다.
    2
    영업 항목을 만듭니다.고객사명, 현재 단계, 내부 담당자와 다음에 할 일을 입력합니다.
    3
    다음 액션일을 지정합니다.대시보드의 오늘 할 일과 지연 알림은 이 날짜를 기준으로 생성됩니다.
    4
    고객 접촉을 활동으로 기록합니다.전화·메일·미팅 결과와 다음 후속 업무를 타임라인으로 남깁니다.
    5
    오늘 할 일을 처리합니다.매일 대시보드에서 지연 업무와 연락이 필요한 고객부터 확인합니다.

    AI 봇 사용 안내
    설정의 매뉴얼과 현재 CRM에 저장된 데이터를 함께 검색하여 사용법, 현황과 다음 행동을 답하는 내부 지식 도우미입니다.
    AI 봇 아이콘의 숫자
    기한이 지난 고객 후속 업무, 높은 중요도의 장기 미접촉 영업 건, 마감일이 지난 실행과제처럼 즉시 확인해야 하는 긴급 항목의 수입니다. 같은 항목에 긴급 사유가 여러 개 있어도 숫자는 한 건으로 계산합니다.
    • 매뉴얼 검색: 화면 목적, 기능 사용법, 입력 기준과 용어 차이를 설정에 저장된 최신 매뉴얼에서 찾아 답합니다.
    • 저장 데이터 분석: 파이프라인, 연락처, 실행과제, 일정, 매출과 입력 누락 현황을 현재 데이터로 집계합니다.
    • 통합 답변: “협상 단계가 무엇이고 현재 몇 건인가?”처럼 사용 기준과 실제 현황을 한 번에 설명합니다.
    • 추천 행동: 단계·일정·누락 정보를 바탕으로 다음에 확인할 업무와 관련 화면을 제안합니다.
    • 실행 지원: 답변 아래 버튼으로 매뉴얼, 영업 항목, 연락처, 실행과제와 활동 기록 화면을 바로 엽니다.
    • 문구 작성: 특정 영업 항목을 기준으로 후속 이메일과 짧은 연락 문구 초안을 작성합니다.
    답변의 한계
    외부 시장정보를 검색하지 않으며, 설정 매뉴얼과 CRM에 저장되지 않은 사실은 임의로 만들지 않습니다. 답변 하단의 근거와 원본 화면을 함께 확인하세요.
